## 1.2.2 重点功能

- 项目文件夹管理：统一管理项目设置、脚本、文件夹和交付归档。
- 文件夹素材约定：自动识别 `6.导出/发布视频.*`、`7.封面/16-9.*`、`7.封面/4-3.*`。
- 临时手动导入：未绑定项目文件夹时，可临时导入视频和封面；临时素材不写入 `.flash`。
- 三平台分发：抖音、小红书接入 social-auto-upload 发布内核；YouTube 入口保留，等待官方 API 账号配置。
- 账号中心：抖音、小红书登录态长期保留，不保存明文密码。
- 一次填写：公共标题、正文、标签、话题和定时信息可统一填写，再按平台补充差异字段。
