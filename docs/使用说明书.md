# 自媒体全能工具使用说明书

适用版本：FlashtecLab 1.2.2。

说明：截图部分应使用空白演示项目，不展示真实文稿。当前 macOS 系统级截图权限返回空画面，因此本版先发布完整文字说明；授予 Codex/终端“屏幕录制”权限后，可补充真实界面截图。

## 1. 软件定位

FlashtecLab 是面向自媒体工作流的桌面工具，核心目标是把“项目管理、脚本、素材、导出、封面、分发”收进同一个工程里。

1. 项目设置：维护项目名称、年份、期数和项目文件夹。
2. 文件管理：按固定文件夹结构管理素材和交付文件。
3. 脚本：维护文稿、脚本表和镜头内容。
4. 分发：一次准备素材和公共内容，向多个平台创建发布任务。
5. 工具：提供 HTML 录屏等生产辅助工具。

## 2. 安装

1. 打开 [Releases](https://github.com/hmg9909/zimeiti-quannengongju/releases)。
2. 下载最新的 `FlashtecLab-1.2.2-macOS.zip`。
3. 解压后把 `FlashtecLab.app` 拖到“应用程序”。
4. 如果 macOS 首次打开提示安全拦截，在“系统设置 - 隐私与安全性”里允许打开。

## 3. 项目设置

项目设置用于决定一个 `.flash` 工程对应哪一期内容。

- 项目名称：显示在侧边栏和导出文件名中。
- 项目编号：由年份和期数组成，例如 `2026·1`。
- 项目文件夹：绑定本期内容的真实文件夹。
- 项目归档：把当前 `.flash` 工程备份到项目文件夹的 `8.交付` 目录。

建议每一期内容都绑定一个项目文件夹。这样分发页可以自动识别发布视频和封面。

## 4. 文件夹约定

项目文件夹使用固定目录结构。分发功能重点依赖两个目录：

| 目录 | 文件命名 | 用途 |
| --- | --- | --- |
| `6.导出` | `发布视频.*` | 最终发布视频 |
| `7.封面` | `16-9.*` | 16:9 横版封面 |
| `7.封面` | `4-3.*` | 4:3 封面 |

如果文件命名不符合约定，分发页会提示缺少素材，而不是弹复杂选择器。

## 5. 分发页总体流程

分发页的目标是一件事：一次准备内容，一键分发到已选平台。

完整流程：

1. 准备素材。
2. 登录平台账号。
3. 填写公共内容。
4. 补充平台差异字段。
5. 勾选要发布的平台。
6. 点击“一键发布到已选平台”。
7. 查看每个平台的发布状态和结果。

## 6. 素材来源

### 项目文件夹模式

如果已经绑定项目文件夹，软件会自动读取：

- `6.导出/发布视频.*`
- `7.封面/16-9.*`
- `7.封面/4-3.*`

这种模式适合长期项目管理，素材会留在项目文件夹里。

### 手动导入模式

如果没有绑定项目文件夹，可以在分发页手动导入一次视频。

- 手动视频只用于本次发布任务。
- 手动素材不写入 `.flash`。
- 没有选择封面时，软件会尝试从视频首帧生成临时封面。
- 发布成功后，临时素材会被清理。
- 发布失败时，临时素材会短期保留，方便重试。

## 7. 账号中心

账号中心用于管理平台登录态。

当前状态：

- 抖音：通过 social-auto-upload 发布内核管理登录态。
- 小红书：通过 social-auto-upload 发布内核管理登录态。
- YouTube：等待官方 API/OAuth 账号配置，暂不启用。

账号中心只保存账号引用和登录状态，不保存明文密码。

常用操作：

- 登录：打开平台登录流程。
- 刷新：检查当前账号 cookie 是否有效。
- 删除：清除该平台登录态。
- 新增账号：为同一平台添加多个账号名，例如 `main`、`work`。

## 8. 一次填写

公共内容会作为三平台的默认发布内容。

字段包括：

- 标题：视频模式必填。
- 正文 / 简介：平台正文或简介。
- 标签：用逗号分隔。
- 话题：平台话题或关键词。
- 定时发布时间：为空则立即发布。

如果某个平台有特殊字段，可以在“平台差异”里覆盖。

## 9. 平台差异

### 抖音

抖音支持的差异字段：

- 发布账号
- 可见范围
- 允许下载
- 位置 / POI
- 商品链接
- 商品标题
- 抖音定时覆盖

### 小红书

小红书支持的差异字段：

- 发布账号
- 笔记标题覆盖
- 笔记类型
- 位置
- 合集 / 专辑
- 小红书定时覆盖

### YouTube

YouTube 当前保留官方 API 路线，账号未创建前不启用。

预留字段包括：

- 隐私状态
- 分类
- 儿童内容声明
- 授权
- 视频语言

## 10. 一键发布

点击“一键发布到已选平台”前，软件会先做预检：

- 是否有发布视频。
- 标题是否已填写。
- 选中的平台是否已登录。
- 平台必填字段是否完整。

预检通过后，软件会为每个平台创建独立任务。

任务状态包括：

- 未开始
- 检查账号
- 上传中
- 发布中
- 已提交
- 失败

一个平台失败不会抹掉其他平台的成功结果。失败平台可以单独重试。

## 11. 常见问题

### 为什么登录成功后还会失败？

登录成功只代表 cookie 有效。真正发布前还需要视频、标题、封面和平台必填字段都完整。

### 为什么提示 title 必填？

视频发布模式下标题是必填项。请先填写公共标题，或填写平台标题覆盖。

### 为什么手动导入素材重开后不见了？

这是设计如此。手动导入素材只用于本次发布任务，不写入 `.flash`，避免工程文件变成素材仓库。

### 为什么 YouTube 不能勾选？

YouTube 账号还没有配置官方 API/OAuth，因此当前禁用。等账号和 API 配置完成后再启用。

## 12. 推荐工作流

1. 为每期视频创建独立项目文件夹。
2. 在项目设置里绑定项目文件夹。
3. 剪辑完成后，把最终视频放到 `6.导出/发布视频.mp4`。
4. 把封面放到 `7.封面/16-9.png` 和 `7.封面/4-3.png`。
5. 进入分发页，确认素材状态。
6. 检查抖音、小红书账号登录态。
7. 填写公共标题、正文、标签和话题。
8. 补充平台差异字段。
9. 勾选平台，一键发布。
